# Settings a studio cannot reach

Generated by `python3 scripts/audit-settings-ui.py` and then checked by hand,
because the script's matching is heuristic in both directions. Re-run it after
any migration that adds a column to `studio_settings` or `membership_plans`.

**Why this list exists.** This project keeps shipping a column with a default and
no way to change it. The occurrence horizon was one — a studio was carrying 1,421
open classes fourteen months out that nobody had agreed to teach and any member
could book. So were `instructor_availability`, `class_types.color`, `class_series`
itself, `member_invites`, `timeline_events`, `cancellation_reason`, and the
nightly reconcile `booked_count` was assumed to have. Each was found by somebody
noticing, months later.

**It also hides broken writers.** `set_series_guarantee()` raised
`column o.flex_confirmed_at does not exist` on every call from migration 081 to
088, because 081 renamed the column and missed that function. Nothing caught it:
the tier had no control, so its only writer was never called. This audit found
the missing setting, and the missing setting found the bug.

## Reachable now

`studio_settings`: 26 of 56 columns have a write path. Decision 22's twelve —
`guarantees_enabled`, `flex_enabled`, the three core settings, the four flex
settings, the two pay figures and `adjacency_minutes` — were added at `/settings`
in this pass, and `guarantee_tier` per series at `/series/[id]`.

`membership_plans`: 23 of 24.
